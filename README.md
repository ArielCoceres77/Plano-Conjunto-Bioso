# Lente Plano · Conjunto Biosol

Realidad aumentada por piezas para el Plano N.º 1 «Conjunto Biosol» (escala 1:10).

Apuntás la cámara a cualquier parte del plano impreso (una vista, un detalle o un sector), ponés la mira sobre una pieza y la app la reconoce, la resalta y muestra sus medidas.

- `index.html`: la app.
- `biosol.mind.gz` / `biosol.mind`: reconocimiento precompilado (30 marcadores: plano, vistas y sectores).
- `lib/`: motor de realidad aumentada (MindAR 1.2.5 + three.js 0.150.1), sin depender de CDN.
- `plano-biosol-marcador.png`: el plano para imprimir.

Publicado en https://arielcoceres77.github.io/Plano-Conjunto-Bioso/
