# Lente Plano · Conjunto Biosol

Realidad aumentada por piezas para el Plano N.º 1 «Conjunto Biosol» (escala 1:10) y modo proyector para calcar.

- **Cámara:** reconoce cada vista o zona del plano por separado (no hace falta enfocarlo entero). La pieza que queda bajo la mira se identifica sola y se muestran sus medidas.
- **Proyector:** guía en 4 pasos, pantalla completa, calibración arrastrando las 4 esquinas (corrige proyector torcido) y avance por los 12 pasos de trazado con ◀ ▶ o las flechas.

Archivos: `index.html` (la app) y `plano-biosol-marcador.png` (el plano para imprimir).
