# Lente Plano · Conjunto Biosol

Realidad aumentada por capas para el Plano N.º 1 «Conjunto Biosol» (escala 1:10) y modo proyector para calcar.

- `index.html`: la app (un solo archivo).
- `plano-biosol-marcador.png`: el plano enderezado para imprimir y enfocar con la cámara.

Publicación: Settings → Pages → rama `main`, carpeta `/ (root)`. La cámara necesita https.
